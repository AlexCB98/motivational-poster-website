# Motivational Poster Website

A simple motivational poster website created with HTML and CSS.

The page features a motivational image, a discipline-focused quote, and a centered layout with a dark visual style.

---

## Features

- Motivational poster design
- Libre Baskerville font from Google Fonts
- Responsive image sizing
- Centered text and content
- Black background with white text
- Custom motivational image
